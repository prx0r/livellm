## How To Run

```bash
# Start API
cd /root/livellm
npm run serve &

# Run bounty demo
python3 archive/demo-bounty.py

# Open report
open archive/bounty-demo-report.html

# Run tests
npm test

# Start MWGym router test
cd /root/mwgym
python3 -c "
from mwgym.market import MarketClient
from mwgym.harnesses.router import DynamicRouter
client = MarketClient()
router = DynamicRouter(market_client=client)
d = router.classify('fix a bug in auth-service')
print(f'Model: {d.market.model}, Score: {d.confidence}')
"
```
