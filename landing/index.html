SerpApi Integration
Not just search — verified discovery
SerpApi is the discovery layer. We use fast Light searches for known signals and Search Index deep mode to explore unknown providers. Every observation keeps the search ID as provenance.

Google News Light

Event detection. Fast, low-cost searches for known pricing terms and provider announcements.

Google Light

Official source resolution. Follows search results to provider pricing pages for evidence extraction.

Search Index Deep

Unknown-source discovery. Explores 3B+ indexed pages to find new providers and offers we weren't looking for.

JSON Restrictor

Reduces response payload by 94-99%. Only the fields we need, cutting agent token costs.

Search Metadata ID

Every search keeps its ID for reproducibility. Search Archive retrieves the exact response for 31 days.

Account API

Free quota governor. Checks searches left before spending. Enforces a reserve to prevent exhaustion.
