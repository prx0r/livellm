**Date:** August 30, 2026
**Status:** API working, demo working, payload audited and corrected

## What Changed Today

### 1. Fixed 5 P0 bugs
- GLM demo: reads from fact ledger (was hardcoded)
- Replay: fails closed on missing fixtures (was falling through to live LLM)
- Validator: unified FIELD_SPEC from schema (was maintaining parallel arrays)
- Zero checks: `== null` not `!value` (0 is a valid price)
- CI: verified working

### 2. Rewrote HTTP API to match product vision
5 endpoints, every response includes freshness + confidence + provenance:
- `GET /v1/market` — route grouping by model, promotions, capabilities
- `GET /v1/models/:model` — full facts per route
- `POST /v1/economics/route` — workload-specific evaluation with confidence
- `GET /v1/changes` — recent changes with change_pct
- `GET /v1/evidence/:id` — full provenance bundle

### 3. Expanded to 22 models across 8 providers
OpenAI, Anthropic, Google, Groq, Mistral, DeepSeek, OpenRouter, OpenCode, Z.ai

### 4. Added comprehensive capability data
Per model: context window, max output, modalities, speed (tok/s), quality tier, batch discount, rate limits, benchmarks (MMLU, HumanEval, Math, Aider)

### 5. Built 3-agent live demo
`npm run live-demo` runs 3 Hermes agents (mimo-v2.5) against the same payload, generates `demo-report.html`

### 6. Corrected pricing for 9 models
Verified against provider websites. Gemini Flash was 5× too cheap, Mistral Large was 4× too expensive, Groq Llama models are now enterprise-only.

## What's Uncertain / Needs Review

### Pricing accuracy
- **OpenCode models** (MiMo, Hy3, Kimi, GLM, GPT 5.6 Luna, DeepSeek V4 Flash, Muse Spark): These are OpenCode Go's internal pricing. We're fairly confident but can't verify against a public page — they're from the OpenCode docs.
- **Z.ai GLM-5.3-Flash**: The 50% promo ($0.075/$0.25) was from recorded fixtures. Unclear if still active.
- **Benchmark scores**: MMLU/HumanEval/Math/Aider scores are approximate public scores, not live-verified. Some are from model cards, some estimated from comparable models. The MMLU scores for Groq gpt-oss models are best-guess since these are newer models with limited public benchmarks.

### Missing providers
- **xAI (Grok)**: Not included. Pricing exists but wasn't added.
- **Cohere**: Not included.
- **Together AI**: Not included (has free tier).
- **Fireworks AI**: Not included (has 1M free tokens/month).

### Missing data points
- **Z.ai route has no context_tokens, quality_tier, speed_tier, benchmarks** — these fields weren't in the Z.ai seed data.
- **OpenCode models have no benchmarks** — we don't have MMLU/HumanEval scores for MiMo, Hy3, Kimi, etc.
- **Free tier limits may be inaccurate** — Groq's free tier for gpt-oss models (14,400/day) is estimated. OpenRouter's 200/day limit is approximate.

### Demo considerations
- The coding agent chose Z.ai GLM-5.3-Flash (128K context, $0.23/mo) instead of MiMo V2.5 (1M context) — this is actually correct since the workload only uses 56K tokens. But the demo narrative might be stronger if we adjust the persona to require 1M context explicitly.
- The demo takes ~60-90 seconds to run (3 sequential Hermes calls). For a live demo, consider pre-running and showing the HTML report.

### What's not wired (intentionally deferred)
- The discovery pipeline (SerpApi radar) is built but not used in the demo — we seed data directly.
- The MCP server is built but not part of the demo flow.
- The HTTP API server works but the demo uses CLI + direct curl, not a deployed server.
- x402 payment integration is not built.
- LiteLLM integration example is not built.
