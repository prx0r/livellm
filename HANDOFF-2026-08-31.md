- Stale prices → agent picks GLM, thinks it's $0.0046/bounty

### The OpenCode Example
- MiMo: 6× subscription value ($60/$10)
- GLM: 1.5× base ($15/$10) + 2× promo = 3×
- GLM amortized: $0.05/M, MiMo: $0.023/M
- Reconciliation: 150,376 calculated ≈ 150,400 published (0.02% error)
- Hy3 conflict: /docs/go/ says 4,300, /go page says 5,400

### The Five Pricing Traps
1. Subscriptions make "price" meaningless
2. Tool pricing is multidimensional
3. Coding subscriptions are everywhere
4. GPU compute changes weekly
5. Official surfaces disagree with themselves
